# Support

Use the repository issue tracker for bugs and feature requests. Include VS Code and extension versions, OS, local/remote workspace type, selected scope/language, provider versions, expected behavior and reproduction steps. Remove secrets and private paths from screenshots and inspection reports.

For confusing formatting behavior, open Diagnostics, then inspect configuration sources in Formatting. An installed provider is not proof that it will format the current file. Higher-priority language or folder settings may override a broader setting.

Pause writes real Workspace/Folder preferences and persists across reloads until Resume / restore. Restore Previous Settings is available in the Command Palette without the dashboard. External edits are preserved. Review remaining conflicts before choosing Keep current values.

Security reports: follow SECURITY.md instead of posting exploit details publicly.
