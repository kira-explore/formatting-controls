# Code of conduct

Treat contributors and users with respect. Welcome different experience levels, give specific constructive feedback, and discuss behavior and code rather than attacking people. Harassment, discrimination, threats, sexualized attention, doxxing and sharing private information without consent are unacceptable.

These expectations apply to repository discussions, issues, pull requests and project-related spaces. Report concerns privately to imrajudhami@gmail.com. Maintainers will review reports, protect private information where possible, and may remove content or restrict participation based on the severity and context. No particular response time is guaranteed. Maintainers are accountable to the same expectations.
